ФДС ПДФ 0.2.0-fds.1-rc1 — предварительная версия для ручной приёмки Windows 11 x64

Распакуйте весь каталог в доступную для записи папку. Запускайте FDS-PDF.exe.
Не переносите отдельно exe: рядом необходимы OCR, LICENSES и остальные файлы.
Установка Python, Tesseract, настройка PATH и подключение к Интернету не требуются.
Значок приложения встроен в exe; FDS-PDF.ico приложен для пользовательских ярлыков.

Распознавание: откройте PDF → Все инструменты → Распознать текст.
Языки: русский и английский. По умолчанию включены поворот и выравнивание страниц.
Результат сохраняется рядом с исходным файлом: <имя>_OCR.pdf.
Если имя занято, добавляется номер. Исходный файл не перезаписывается.
Для документа без пути предлагается выбрать место сохранения.
Во время обработки можно отменить операцию. После завершения нажмите «Открыть результат».
При ошибке откройте «Технические сведения». Документы обрабатываются локально.

Runtime: Python 3.13.15, OCRmyPDF 17.4.0, Tesseract 5.5.3.20260724; rus/eng/osd.
SHA256SUMS.json содержит состав и контрольные суммы комплекта.
Лицензии, уведомления, исходники внешнего runtime и рецепты сборки находятся в LICENSES.
См. THIRD-PARTY-NOTICES.txt. Этот RC не прошёл ручную приёмку на рабочем ПК.
